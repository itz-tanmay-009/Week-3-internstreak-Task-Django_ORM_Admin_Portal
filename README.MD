# Django Data Persistence Layer & Admin Portal

## Project Overview

This project is developed using Django. It manages students, courses, and student enrollments through Django ORM and the Django Admin Portal.

## Technologies Used

- Python
- Django
- SQLite
- Django ORM
- HTML
- CSS

## Main Features

- Student management
- Course management
- Enrollment management
- Database relationships using ForeignKey
- Django Admin dashboard
- Student, course, and enrollment data display
- HTML dashboard with database records
- Search and filtering in Django Admin

## Database Models

### Student

Stores student name, email, age, and creation date.

### Course

Stores course name, course code, and duration.

### Enrollment

Connects students with courses using ForeignKey relationships.
